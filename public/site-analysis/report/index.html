Detailed Findings

Finding SEC-001: Missing Content Security Policy Header

Severity: Medium Category: HTTP Security Headers

Description: The HTTP response did not include the Content-Security-Policy response header. This header defines approved sources of content that browsers are allowed to load.

Evidence: The Content-Security-Policy header was not present in the HTTP response. Observed headers: Cache-Control: max-age=3600 Content-Type: text/html; charset=utf-8 Strict-Transport-Security: max-age=31556926; includeSubDomains; preload

Impact: Without a content security policy, the application has no browser-enforced restrictions on content sources, which may increase exposure to cross-site scripting and data injection.

Recommendation: Deploy a Content-Security-Policy header. Start with a report-only policy to identify legitimate content sources before enforcing.

References:

  • https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Security-Policy

Finding SEC-005: Missing Clickjacking Protection Header

Severity: Medium Category: HTTP Security Headers

Description: The HTTP response did not include the X-Frame-Options header or a Content-Security-Policy with a frame-ancestors directive. These headers prevent the page from being embedded in frames on other origins.

Evidence: The X-Frame-Options / frame-ancestors header was not present in the HTTP response. Observed headers: Cache-Control: max-age=3600 Content-Type: text/html; charset=utf-8 Strict-Transport-Security: max-age=31556926; includeSubDomains; preload

Impact: The page may be embeddable in frames on third-party sites, which could facilitate clickjacking attacks.

Recommendation: Set the X-Frame-Options header to DENY or SAMEORIGIN, or configure a Content-Security-Policy with an appropriate frame-ancestors directive.

References:

  • https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/X-Frame-Options

Finding SEC-002: Missing X-Content-Type-Options Header

Severity: Low Category: HTTP Security Headers

Description: The HTTP response did not include the X-Content-Type-Options response header. This header prevents browsers from MIME-sniffing a response away from the declared content type.

Evidence: The X-Content-Type-Options header was not present in the HTTP response. Observed headers: Cache-Control: max-age=3600 Content-Type: text/html; charset=utf-8 Strict-Transport-Security: max-age=31556926; includeSubDomains; preload

Impact: Browsers may attempt to guess the content type of responses, which could lead to security issues if the guessed type differs from the declared type.

Recommendation: Configure the web server to return X-Content-Type-Options: nosniff.

References:

  • https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/X-Content-Type-Options

Finding SEC-003: Missing Referrer-Policy Header

Severity: Low Category: HTTP Security Headers

Description: The HTTP response did not include the Referrer-Policy response header. This header controls how much referrer information is included with navigation requests.

Evidence: The Referrer-Policy header was not present in the HTTP response. Observed headers: Cache-Control: max-age=3600 Content-Type: text/html; charset=utf-8 Strict-Transport-Security: max-age=31556926; includeSubDomains; preload

Impact: Full referrer information may be sent to third-party sites on navigation, potentially exposing URL paths, query parameters, or other sensitive data.

Recommendation: Configure the web server to return a Referrer-Policy header such as strict-origin-when-cross-origin or no-referrer.

References:

  • https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Referrer-Policy

Finding SEC-004: Missing Permissions-Policy Header

Severity: Low Category: HTTP Security Headers

Description: The HTTP response did not include the Permissions-Policy response header. This header restricts which browser features the site can use.

Evidence: The Permissions-Policy header was not present in the HTTP response. Observed headers: Cache-Control: max-age=3600 Content-Type: text/html; charset=utf-8 Strict-Transport-Security: max-age=31556926; includeSubDomains; preload

Impact: Without a permissions policy, the browser grants default access to features such as camera, microphone, and geolocation, which could be exploited via cross-site scripting.

Recommendation: Deploy a Permissions-Policy header that restricts browser features to only those required by the application.

References:

  • https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Permissions-Policy

Finding SEC-006: Missing Cross-Origin Isolation Headers

Severity: Low Category: HTTP Security Headers

Description: The HTTP response did not include one or more cross-origin isolation headers (COOP, COEP, CORP, or related policies). These headers reduce the risk of cross-origin side-channel attacks.

Evidence: Missing headers: cross-origin-embedder-policy, cross-origin-opener-policy, cross-origin-request-policy, cross-origin-resource-policy Observed headers: Cache-Control: max-age=3600 Content-Type: text/html; charset=utf-8 Strict-Transport-Security: max-age=31556926; includeSubDomains; preload

Impact: Without cross-origin isolation headers, the site may be more susceptible to cross-origin information leakage through side-channel attacks.

Recommendation: Evaluate and deploy Cross-Origin-Opener-Policy, Cross-Origin-Embedder-Policy, and Cross-Origin-Resource-Policy headers as appropriate for the application.

References:

  • https://developer.mozilla.org/en-US/docs/Web/HTTP/Cross-Origin_Opener_Policy

Finding SEC-007: Non-Restrictive Cache-Control Directive

Severity: Low Category: HTTP Security Headers

Description: The Cache-Control header was set without directives that prevent caching of potentially sensitive responses.

Recommendation: Include no-store, no-cache, private, or must-revalidate in the Cache-Control header for responses containing sensitive data.
